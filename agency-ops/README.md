# Sistema de Operaciones — Agencia de Marketing Digital

Sistema repetible para convertir un negocio (principalmente restaurantes) en cliente activo:

`NEW LEAD → AUDIT → DEMO → CONTACTED → MEETING → PROPOSAL → WON → ONBOARDING → ACTIVE CLIENT → COMPLETED`

## Cómo usar este sistema

1. Cuando aparece un nuevo prospecto, copia `clients/_TEMPLATE/` a `clients/<nombre-del-negocio>/`.
2. Antes de crear el prospecto, búscalo por nombre o website en `crm/pipeline.md` para evitar duplicados. Si ya existe, actualiza esa fila en vez de crear una nueva.
3. Completa cada archivo numerado en orden, solo con información real y verificable. Si un dato no está disponible, escríbelo como "No disponible" — nunca se inventa.
4. Actualiza la etapa (`stage`) en `crm/pipeline.md` conforme el prospecto avanza por el pipeline.
5. Antes de la entrega final, completa `10-delivery-checklist.md` sin excepciones.

## Estructura

- `crm/pipeline.md` — tablero maestro de todos los leads/clientes y su etapa actual.
- `clients/_TEMPLATE/` — plantilla con un archivo por fase: investigación, auditoría, demo, deployment, sistema de reviews, fotografía, propuesta, CRM, onboarding y entrega.

## Reglas fijas

- No se inventa información: website, reviews, fotos, contacto, etc. deben venir de fuentes reales y verificables.
- No se publican cambios destructivos, pagos ni comunicaciones externas importantes sin autorización explícita.
- No se falsifican testimonios ni reviews.
- No se duplican contactos en el CRM.
- No se garantizan resultados en propuestas comerciales.
